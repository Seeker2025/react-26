for ... in может перебрать элементы в массиве и вернуть индексы?
Да! Именно так. for...in может перебирать массив и возвращать его индексы.

Например:

const fruits = ['apple', 'banana', 'orange'];

for (const index in fruits) {
  console.log(index);
}

Результат:

0
1
2

Если нужны сами элементы, обращаемся к массиву по индексу:

for (const index in fruits) {
  console.log(fruits[index]);
}

Результат:

apple
banana
orange

Но есть важный нюанс
Для перебора массивов обычно рекомендуют использовать for...of, а не for...in.

for (const fruit of fruits) {
  console.log(fruit);
}

Почему? Потому что for...of перебирает непосредственно значения массива, а for...in — перечисляемые ключи, включая дополнительные свойства и потенциально свойства прототипа.

Запомни:

for...in → индексы массива.

for...of → элементы массива.



Запомни:
Тип данных	for...in	            for...of
Object	    Ключи	                Не работает напрямую
Array	    Индексы	                Элементы
Set	        Не перебирает элементы	Элементы
String	    Индексы	                Символы

Главное: Set — итерируемая коллекция, поэтому для неё используем for...of.
