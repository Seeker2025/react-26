В JavaScript есть несколько способов преобразовать что-либо в массив. Самые
распространённые:
1. Array.from() — преобразует в массив
Работает со строками, Set, Map, NodeList и другими итерируемыми или
массивоподобными объектами.
const str = 'Hello';

const arr = Array.from(str);

console.log(arr); // ['H', 'e', 'l', 'l', 'o']


2. Spread ... — оператор разворота
const numbers = new Set([1, 2, 3]);

const arr = [...numbers];

console.log(arr); // [1, 2, 3]


3. Array.of() — создаёт новый массив из переданных аргументов
const arr = Array.of(10, 20, 30);

console.log(arr); // [10, 20, 30]


4. .split() — преобразует строку в массив
const str = 'яблоко,груша,слива';

const arr = str.split(',');

console.log(arr); // ['яблоко', 'груша', 'слива']


Главное отличие
Способ	Для чего
Array.from()	Преобразование итерируемых и массивоподобных объектов
[...value]	Разворачивание итерируемых значений в массив
Array.of()	Создание массива из аргументов
split()	Разделение строки на элементы массива

Совет: запомни прежде всего Array.from() и оператор .... Они особенно часто
встречаются в JavaScript и React.
